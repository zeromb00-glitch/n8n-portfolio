# n8n Portfolio — Automation Solutions for Accounting Firms

## About

This repository documents automation workflows built with [n8n](https://n8n.io), focused on solving real operational problems for accounting and bookkeeping firms in Europe — document processing, client onboarding, reconciliation support, and recurring reporting.

Each project here is either a live client solution (anonymized) or a demonstration build showing the approach used to solve a specific problem.

## Stack

- **n8n** — workflow automation and orchestration
- **PostgreSQL + pgvector** — data storage and semantic search for document-based workflows
- **Docker** — local development and deployment
